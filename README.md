  A Lenda de Marco Aurélio
  
Um site criado com HTML e CSS sobre Marco Aurélio e o estoicismo.

  Sobre o projeto
  
Este projeto foi desenvolvido com o objetivo de praticar HTML e CSS,
além de compartilhar reflexões sobre Marco Aurélio, filosofia estoica
e desenvolvimento pessoal.

 Tecnologia utilizada
  
HTML5
CSS3
